An ADR records a decision and the reasoning behind it, so that six months from now the question

Two rules that make ADRs worth writing:

  1. **Write the alternative down and say why it lost.** An ADR that only describes what you did is

  2. **Never rewrite one.** A decision that changes gets a *new* ADR that supersedes the old one, or
